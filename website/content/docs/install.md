DevFiller is free in the extension store of each browser it supports, and the store keeps it up to date. Your settings, custom fields and exclusions are kept across updates.

## Chrome

1. Open [DevFiller on the Chrome Web Store]({{chromeStoreUrl}}).
2. Click **Add to Chrome**, then **Add extension**.
3. Pin DevFiller from the Extensions menu (the puzzle icon) so its icon stays in your toolbar.

DevFiller needs Chrome 118 or later. Brave, Opera, Vivaldi and other Chromium browsers install it from the Chrome Web Store too.

## Firefox

1. Open [DevFiller on Firefox Add-ons]({{firefoxStoreUrl}}).
2. Click **Add to Firefox**, then **Add**.
3. Pin it from the Extensions menu (the puzzle icon) so its icon stays in your toolbar.

DevFiller needs Firefox 140 or later. In Firefox the panel opens in the sidebar.

## Microsoft Edge

1. Open [DevFiller on Microsoft Edge Add-ons]({{edgeStoreUrl}}).
2. Click **Get**, then **Add extension**.
3. Show it in the toolbar from the Extensions menu (the puzzle icon).

A welcome page opens after the first install. You can reopen it later from the extension's options.

## Fill your first form

1. Open any page with a form, for example a sign-up page on your local development server.
2. Click the DevFiller icon. The fields fill, and the icon shows how many.
3. Click again for a new identity and new values.

If the icon shows `!`, the page couldn't be filled. Browser pages such as `chrome://` and `about:` pages, and the extension stores themselves, don't allow extensions.

The first time you use DevFiller on a site, your browser may ask you to allow it on that site. DevFiller only reads the page you click it on; see [Privacy and permissions](/docs/privacy-permissions/).

## Shortcuts and menus

| Action | How |
| --- | --- |
| Fill the current page | Click the toolbar icon |
| Open the side panel (the sidebar in Firefox) | Press **Alt+Shift+F**, or right-click the icon → **Open DevFiller panel** |
| Open the settings | Right-click the icon → **Options** (in Firefox, **Manage Extension**, then **Preferences**) |

You can change the shortcut at `chrome://extensions/shortcuts` in Chrome, `edge://extensions/shortcuts` in Edge, and in Firefox under `about:addons` → the gear menu → **Manage Extension Shortcuts**.

## Working on DevFiller itself

If you want to change DevFiller or run its tests, see [Build from source](/docs/build-from-source/). Everyone else should install it from their browser's store, which keeps it up to date.
