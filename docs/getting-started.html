The setup

Four steps, in order.

Formly ships as an unpacked extension, so you build it once and point the browser at the output folder. Each step below ends with something you can see.

1

Build the extension

Node.js 22 and npm, matching what CI uses. The build type-checks the project and writes the loadable extension into dist/.

git clone https://github.com/gouderhaithem/form-filler.git
cd form-filler
npm ci
npm run build

You should seea dist/ folder containing manifest.json.

2

Load it into your browser

Open chrome://extensions (or edge://extensions), turn on Developer mode in the corner, click Load unpacked, and choose the dist/ folder — the folder itself, not a file inside it.

You should seea Formly card on the extensions page, and its welcome guide opening in a new tab.

3

Pin it to the toolbar

Open the browser's puzzle-piece Extensions menu and pin Formly. The toolbar icon is how you fill — there is no popup to open first, and a click acts on the tab you are looking at.

You should seethe Formly icon sitting in your toolbar.

4

Fill your first form

Open any page with a form and click the icon. Names, emails, phone numbers, addresses, dates and dropdowns fill together as one coherent fictional person. Click again for a completely new set. Nothing is ever submitted for you — pressing the submit button stays your decision.

You should seea number on the icon: how many fields were filled.

Make it yours

Three settings worth knowing on day one.

Right-click the icon and choose Options. Everything here is optional — Formly fills perfectly well before you touch any of it.

Custom values

Some fields need one exact value every time — a tenant ID, a test account number, a project code your API validates.

Project code → PRJ-001

Excluded fields

Protect anything that should stay untouched, by label or CSS selector, for one site or everywhere. Search boxes and navigation controls are already skipped.

Skip on this site → #site-search

Gemini & its cache

Bring your own API key to get sensible text for fields the local generator doesn't recognize, like Why are you interested? Suggestions are cached, and you set for how long.

Cache expiry → 1–60 min

Good to know

What Formly deliberately won't do.

Worth reading once, so nothing surprises you mid-test.

Never submits a form. Filling stops at the values. You press submit.

Skips sensitive fields. Payment, one-time codes and consent checkboxes are left alone. So are file uploads and read-only inputs.

Top-level document only. Fields inside iframes, shadow DOM or rich-text editors need adapters that don't exist yet.

The data is fictional. Sample pools are finite, so values repeat eventually, and a site's own validation may still reject one.

Nothing leaves your machine by default. Settings stay in local extension storage. There is no sync and no Formly server.

Gemini sees labels, not answers. Only field descriptions and your chosen language are sent — never the values in the form.

If something looks wrong

The four things that trip people up.

What you seeWhat it meansWhat to do
Clicking the icon does nothing The page restricts extensions — browser settings pages, the extension gallery and chrome:// URLs all do. Try it on an ordinary website. Hover the icon to read the reason.
An ! badge and an empty form Gemini failed with something other than a quota error, and Formly leaves the form untouched rather than guessing. Click again — these are usually brief. If it persists, switch off Use Gemini for unknown fields and fill locally.
The first click takes a few seconds Suggestions are still being prepared, so Fill waits for them instead of filling twice. Nothing. Later clicks come from the cache and are instant until it expires.
A field keeps its old value It is excluded, read-only, or one of the sensitive types Formly skips on purpose. Open the side panel with Alt + Shift + F to see the reason for every field.
